Full Stack Product Management Application

A full-stack web application for managing products using React, Express, and PostgreSQL. This project demonstrates how to build a REST API and connect a frontend to a backend with a real relational database.



Features

Create new products

View a list of products

Update product names and prices

Toggle product availability

Delete products

Persist data in PostgreSQL



Tech Stack

Frontend: React, React Router DOM

Backend: Node.js, Express

Database: PostgreSQL

ORM: Sequelize

Language: TypeScript

Validation: Express Validator

API Documentation: Swagger

Testing: Supertest

Logging: Morgan

Cross-Origin Requests: CORS



Key Learning Objectives

Build and consume a REST API

Implement CRUD operations (Create, Read, Update, Delete)

Connect React with an Express backend

Manage persistent data using PostgreSQL and Sequelize

Validate incoming requests

Document API endpoints with Swagger

Test API functionality using Supertest

Apply client-server architecture and full-stack development best practices

This project is part of my journey toward becoming a Full Stack Developer, focusing on building scalable, maintainable, and well-structured web applications.
